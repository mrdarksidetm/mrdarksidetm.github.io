## 🌟 Overview

This is the source code for my professional portfolio and software showcase. Built with a focus on **Material 3 precision** and **Editorial design**, it serves as the home for my privacy-first applications and system optimization toolkits.

### 🚀 Featured Softwares

*   **[Wallet (Paisa)](https://github.com/mrdarksidetm/Wallet):** The ultimate personal finance dashboard. 100% offline, local-first, and designed with Material 3 precision.
*   **[WinForge v5.0](https://github.com/mrdarksidetm/winforge):** Next-gen Windows 11 optimization toolkit. Reclaim privacy with AI/Recall purge and boost performance with the Game Mode engine.

## 🛠️ Technical Stack

This project leverages a modern, high-performance frontend stack:

*   **Framework:** [React 19](https://react.dev/) + [Vite 8](https://vitejs.dev/)
*   **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (The "Stitched" Grid Aesthetic)
*   **Animation:** [Framer Motion](https://www.framer.com/motion/) (Tactile interactions)
*   **Icons:** [Lucide React](https://lucide.dev/)
*   **Language:** [TypeScript](https://www.typescriptlang.org/)

## 📥 Development

### Prerequisites
- [pnpm](https://pnpm.io/) (Recommended) or npm/yarn

### Setup
```bash
# Clone the repository
git clone https://github.com/mrdarksidetm/mrdarksidetm.github.io.git

# Install dependencies
pnpm install

# Start development server
pnpm dev
```

### Build & Deploy
The project is configured for automated deployment to GitHub Pages via the `main` branch.
```bash
# Generate production build
pnpm build
```

## 🎨 Design Philosophy: "The Stitch"

The design follows the **Stitch** methodology—a blend of high-contrast typography, geometric grid systems (the "stitch-grid"), and Material 3's tonal elevation. Every interaction is designed to feel "tactile" and deliberate, mirroring the engineering quality of the software it showcases.
